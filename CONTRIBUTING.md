# Contributing

Read AGENTS.md and the issue first. Use a focused issue branch, preserve unrelated work, and open a PR that explains behavior, checks, platform coverage, migration/security impact and remaining risks. Use synthetic data. Changes that affect shared architecture or storage require explicit review; the product owner approves merges and releases. No build or CI commands exist yet: U-03 and U-04 establish and verify them.

GitHub reported on 2026-11-10 that branch protection rules would not be enforced while this repository was private under the current account plan. The repository has since been made public, so availability must be re-verified under U-04. Until enforcement is available and verified, the product owner must manually confirm the PR, independent review, applicable checks and final approval before merging. No required status checks exist until genuine CI is established.

# Roadmap

All milestones are open and have no due dates. Completion requires demonstrated outcomes, not just issue creation.

1. [M1 Foundation and repository setup](https://github.com/arlecchinoOPSource/Unhollowed/milestone/1): scaffold, verified Core integration, architecture and workflow.
2. [M2 Embedded application integration](https://github.com/arlecchinoOPSource/Unhollowed/milestone/2): three functional embedded apps without standalone executables.
3. [M3 Data and history compatibility](https://github.com/arlecchinoOPSource/Unhollowed/milestone/3): verified persistence, migrations, concurrency and integrity.
4. [M4 Rack and projector modeling](https://github.com/arlecchinoOPSource/Unhollowed/milestone/4): integrated rack, projector assets, materials and lighting.
5. [M5 Holograms and sensory systems](https://github.com/arlecchinoOPSource/Unhollowed/milestone/5): working interfaces, power, animation, indicators and audio.
6. [M6 Testing and version 1.0 release readiness](https://github.com/arlecchinoOPSource/Unhollowed/milestone/6): regression, native packaging, accessibility, performance, security and owner release approval.

The [requested backlog and dependencies](BACKLOG-DRAFT.md) records U-01 through U-30. The identifiers link to their GitHub issues; independently progressing work need not wait for an entire milestone.

# Product

UNHLW is a local-first desktop suite for people using Terminal, Ember and Swish. A user should be able to install UNHLW alone and use the real features of all three applications; standalone distributions remain supported. Projector power controls the application surface, while decorative controls must not alter personal data. Keyboard operation, configurable sound, reduced motion and readable interfaces are requirements.

Version 1.0 targets macOS and Windows, functional embedded apps, safe data compatibility and recovery, an industrial rack and three projector identities, accessible projection and sound, and native release verification. Accounts, cloud sync, telemetry, replacement of standalone products, and dependence on a real-time 3D engine are not approved scope. Open decisions include exact lifecycle behavior, conflict resolution, data locations and sharing, visual dimensions, signing, and updates. The product owner decides direction and accepts scope.
